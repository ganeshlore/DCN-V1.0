# GitHub and GitBook Setup

1. Create a new GitHub repository.
2. Upload all files and folders from this package to the repository root.
3. In GitBook, create or open a Space.
4. Enable Git Sync and connect the GitHub repository.
5. Select the repository root as the project directory.
6. GitBook will read `.gitbook.yaml`, `README.md`, and `SUMMARY.md` to build the navigation.

Do not upload the outer ZIP file into the repository. Extract it first and upload its contents.
